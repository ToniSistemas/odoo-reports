Payment Receipt Report Module for Odoo 18.0 =========================================== This module provides a comprehensive solution for generating payment receipt PDFs directly from invoices. Key Features: ------------- ✓ Generate professional payment receipt PDFs ✓ Works with any invoice, regardless of payment status ✓ Includes company logo and branding ✓ Customer and invoice information display ✓ One-click button in invoice form ✓ Fully compatible with Odoo 18.0 Screenshot Preview: ------------------- The payment receipt includes: - Company header with logo - "COMPROBANTE DE PAGO" title - Customer information (name, address, locality, tax ID) - Invoice details (number, dates, reference) - Highlighted total amount box - Payment status indicator (when paid) - Professional footer with company info Installation: ------------- 1. Place this module in your Odoo addons directory 2. Update the apps list 3. Install "Payment Receipt Report" from Apps menu Usage: ------ Open any customer invoice and click "Imprimir Comprobante de Pago" button in the header.
